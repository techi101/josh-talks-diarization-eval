How to read this

DER = share of speech time a system gets wrong (missed + false alarm + wrong speaker). Lower is better. Strict scoring by default: 0 ms collar, overlap scored, speaker count not given. Groups come from a paired session bootstrap; a lead smaller than the interval is not a win. "Empty / partial" = sessions where the system returned speech for under half the reference speech.
